## Human Intelligence

We see thought the eyes -> the variations of light perceived by the eyes are converted to an electrical stimuly -> 
the signal is sent to the brain thanks to a neuron and there is processed.

# Machine Intelligence
Machine see thought a camera -> the variations of light perceived are converted to an image in pixels -> 
the is processed and thanks to algorithms the machine can be enabled to recognise what is in the picture

## IMAGES CLASSIFICATION TASK in machine learning

--

## 1. CREATION OF A DATASET

First of all we need to create the pool of data that than the machine will have to recognise.

We can have different pictures portraing several subjects and we have to label each picture with its own Class.

--

## 2. TRAINING OF THE MODEL

We show to the system all the images with the label associated. In this way the machine will identify similarities between the different images and learn to classify them.

--

## 3. TEST THE MODEL

Once the Machine Learning algorithm has been trained we need to test it to check if the machine has really learned from the data!!

PS: We have always to test the algorithm with images different from the one used in the trining phase!
