## Sight

* While we use our eyes to see...
  * computers use cameras <!-- .element class="fragment"-->
* Both cameras and eyes are light sensors that enable sight.  <!-- .element class="fragment"-->

![](presentation_girls_in_ict/images/polly_enlightened.svg)<!-- .element style="position: fixed; bottom: 30px; right: -130px; width:300px" -->

--

### Human sight and intelligence

* Humans see through their eyes
  * Variations of light perceived are converted to an electrical signal  <!-- .element class="fragment"-->
  * The signal is sent to the brain thanks to neurons  <!-- .element class="fragment"-->
  * The brain processes and interprets it.  <!-- .element class="fragment"-->

--

### Machine sight and intelligence

* Computers see through a camera 
  * Variations of light perceived are converted to an image made of pixels <!-- .element class="fragment"-->
  * The signal is processed in a micro-processor (CPU)  <!-- .element class="fragment"-->
  * Computer programs are used recognise what is in the picture.  <!-- .element class="fragment"-->

--

## Image Classification Tasks <br>in machine learning

1. Dataset Creation
1. Model Training
1. Model Testing

--

## 1. Dataset Creation

* First of all, we need to create the pool of data that the machine will have to recognize.
* We can have different pictures portraying several subjects ... <!-- .element class="fragment"-->
* and we have to label each picture with its own Class. <!-- .element class="fragment"-->

--

## 2. Model Training

* We show the system all the images with the associated label.
* In this way, the machine will identify similarities between the different images... <!-- .element class="fragment"-->
* and learn to classify them. <!-- .element class="fragment"-->

--

## 3. Model Testing

* Once the Machine Learning algorithm has been trained ...
* we need to test it to check if the machine has really learned from the data ! <!-- .element class="fragment"-->
* ⚠️ We always test the algorithm with images different from the ones used in the training phase! <!-- .element class="fragment"-->

--

## How do we deal with other intelligence types ?

* The same approach can be used to train other kind of machine intelligences...
* like the kinestetic or the auditory ones !
