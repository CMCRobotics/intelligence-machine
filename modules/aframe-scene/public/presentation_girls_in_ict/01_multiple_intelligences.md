#### Multiple intelligence theory

* Howard Gardner’s Multiple Intelligences Theory states that :
  * Intelligence is not a single general ability... <!-- .element class="fragment"-->
    * but a set of different, independent intelligences. <!-- .element class="fragment"-->
  * Each person has a unique combination of these intelligences... <!-- .element class="fragment"-->
    * influencing how they learn and interact with the world. <!-- .element class="fragment"-->
