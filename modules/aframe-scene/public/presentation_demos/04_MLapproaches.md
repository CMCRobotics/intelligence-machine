
### Did you know that a machine can learn following different approaches?

* Supervised 
* Unsupervised 
* Reinforcement learning 

![](presentation_demos/images/polly_enlightened.svg)<!-- .element style="position: fixed; bottom: 50px; right: -120px; width:250px" -->

--
### Supervised learning

You show the machine many examples of input together with the correct output so it can learn to recognise the output.

(as when we teach a child their name)

--
### Unsupervised learning

The machine does not have predefined classification, so it creates clusters to associate similar objects.

(as when you don't know the names of trees but you can distinguish and group them into categories)

--
### Reinforcement learning

The machine receives a positive reward when it acts correctly and a negative reward otherwise.

(like giving or not giving candy to a child depending on their behaviour)
